### Olá, eu sou a Vitória Rodrigues! 👋

Sou mestranda em **Ciência de Dados para Ciências Sociais** na Universidade de Aveiro. O meu foco é utilizar a tecnologia para ajudar a resolver problemas complexos da sociedade, como saúde pública, mobilidade urbana, inteligência científica, etc.

Estou construindo um portfólio que une a precisão da engenharia de dados com a interpretação das ciências sociais.

### 🛠️ Tech Stack & Ferramentas

Com base nos meus projetos recentes, estas são as tecnologias que utilizo:

* **Linguagens:** Python, SQL.

* **Análise Geoespacial (GIS):** PostGIS, QGIS, TravelTime API, Análise de Isócronas.

### 🔭 Projetos em Destaque

#### 1. 🔬 [Observatório da Comunidade Científica](https://github.com/Vitoria-analyst/Observatorio-da-Comunidade-Cientifica)
Um dashboard de inteligência bibliométrica que monitoriza a produção científica da UA.
* **Tech:** NLP, Topic Modeling (NMF), Llama 3, Streamlit.
* **Destaque:** Rotulagem automática de tópicos complexos usando LLMs.

#### 2. 🌍 [Geometrias da Desigualdade](https://github.com/Vitoria-analyst/Geometrias-da-Desigualdade)
Análise espacial comparativa sobre mobilidade urbana e acesso no Brasil.
* **Tech:** PostGIS, SQL, QGIS, Mapbox.
* **Destaque:** Comparação de isócronas (carro vs. transporte público) para identificar exclusão social.
